# Apk Medidor de IMC

Aplicativo Mobile compatível com Apple e Android para calcular o Índice de Massa Corporal (IMC).

## Descrição

Este projeto é um aplicativo simples desenvolvido em **JavaScript** utilizando **React Native**, **Node.js** e **Expo**. Ele calcula o IMC de um usuário com base no peso e altura fornecidos. O aplicativo é projetado para funcionar tanto em dispositivos Android quanto iOS.

## Estrutura do Projeto

A estrutura de diretórios do projeto é organizada da seguinte maneira:


### Detalhes dos Arquivos

- **`App.js`**: Arquivo principal que carrega os componentes `Title` e `Main`.
- **`app.json`**: Configuração do aplicativo, incluindo ícones, splash screen e outras propriedades específicas das plataformas.
- **`assets/`**: Contém imagens e ícones utilizados no aplicativo.
- **`src/components/`**: Contém os componentes reutilizáveis do aplicativo, como `title`, `Main`, e `Form`.

## Tecnologias Utilizadas

- **React Native**: Framework para desenvolvimento de aplicativos móveis.
- **JavaScript**: Linguagem principal utilizada.
- **Node.js**: Ambiente de execução para desenvolvimento do projeto.
- **Expo**: Ferramenta para facilitar o desenvolvimento e testes do aplicativo.

## Funcionalidades

- Cálculo do IMC: Insira seu peso e altura para calcular o IMC.
- Compatibilidade com múltiplas plataformas: Funciona em dispositivos iOS e Android.
- Design Responsivo: Interface adaptada para diferentes tamanhos de tela.
